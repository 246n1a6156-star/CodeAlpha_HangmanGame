# CodeAlpha Hangman Game

## Project Description
A simple text-based Hangman game developed using Python.

## Features
- Uses a list of predefined words.
- Player guesses one letter at a time.
- Allows a maximum of 6 wrong guesses.
- Displays correct and incorrect guesses.
- Shows the word when the game ends.

## Technologies Used
- Python

## How to Run
1. Open the project in VS Code.
2. Run `hangman.py`.
3. Enter one letter at a time.
4. Try to guess the word before 6 wrong guesses.

## Concepts Used
- Lists
- Strings
- Random module
- While loop
- If-else statements
- User input
